🐙GitHub는 뭐예요?

GitHub는 코드를 관리하고 저장하는 클라우드 저장소입니다. 구글 드라이브처럼 생각하면 됩니다!

왜 GitHub를 사용할까요?

  • 📝 코드를 안전하게 보관할 수 있어요
  • 👥 팀원과 함께 협업할 수 있어요
  • 📈 코드 변경 이력을 모두 기록해요
  • 🔄 문제가 생기면 이전 버전으로 되돌릴 수 있어요
💡 쉽게 비유하면: GitHub = 코드를 위한 Google Drive + Time Machine

우리 프로젝트에서:

저장소 주소: https://github.com/KDO-80/HRsupport001

이곳에 모든 코드가 저장되어 있어요!

💻Node.js는 뭐예요?

Node.js는 자바스크립트를 서버(컴퓨터)에서 실행하게 해주는 도구입니다.

Node.js의 역할:

  • 자바스크립트 코드를 실행해요
  • 웹 서버를 만들 수 있어요
  • 데이터베이스와 통신해요
  • 파일을 다루고 처리해요

NPM (Node Package Manager)

NPM은 Node.js의 가게처럼 생각하면 됩니다. 누군가 만든 유용한 도구들을 다운로드할 수 있어요!

npm install [패키지이름]

위 명령어로 필요한 패키지를 설치합니다.

💡 쉽게 비유하면: Node.js = 자바스크립트를 서버에서 돌리는 엔진
NPM = 자바스크립트 도구들을 다운받는 온라인 마켓

⚡Next.js는 뭐예요?

Next.js는 웹사이트를 빠르고 쉽게 만들기 위한 도구입니다.

Next.js의 특징:

  • React라는 라이브러리를 기반으로 해요
  • 페이지가 매우 빨리 로드돼요
  • API 서버도 함께 만들 수 있어요
  • 배포하기가 쉬워요 (Vercel)

🗄️Supabase는 뭐예요?

Supabase는 데이터를 저장하는 클라우드 데이터베이스입니다. 엑셀처럼 표 형태로 데이터를 저장해요!

Supabase의 역할:

  • 📊 사용자 정보를 저장해요
  • 📁 업로드된 파일 정보를 저장해요
  • 💾 분석 결과를 저장해요
  • 🔐 데이터를 안전하게 보호해요

우리 프로젝트에서:

프로젝트 ID: tswkgzikqbwodknhxqok URL: https://tswkgzikqbwodknhxqok.supabase.co

모든 데이터가 이곳에 저장됩니다!

💡 쉽게 비유하면: Supabase = 클라우드 엑셀 + 보안

🤖Claude API는 뭐예요?

Claude API는 인공지능을 사용할 수 있게 해주는 서비스입니다. 우리 앱이 파일을 분석하고 답변할 수 있게 해줘요!

Claude API의 기능:

  • 📄 파일 내용을 이해해요
  • ❓ 질문에 지능적으로 답해요
  • 📊 데이터를 분석해요
  • 💡 자동으로 요약을 만들어요
💡 쉽게 비유하면: Claude API = 매우 똑똑한 AI 비서

❓자주 묻는 질문 (FAQ)

Q: npm run dev가 안 돼요

A: Node.js가 제대로 설치되지 않았을 수 있습니다.
node --version과 npm --version을 실행해보세요!

Q: package.json이 뭐예요?

A: 프로젝트의 설명서입니다. 필요한 패키지들과 버전이 모두 기록되어 있어요.

Q: node_modules 폴더가 너무 커요

A: 정상입니다! 모든 패키지가 저장되는 곳이에요. GitHub에는 올리지 않습니다.

Q: API 키를 잃어버렸어요

A: 다시 만들면 됩니다! Supabase나 Claude 콘솔에서 새 키를 생성하세요.
